# ParchaOS app icons

Original ParchaOS artwork (hand-written SVG), made to replace icons in the
MacTahoe theme that reproduce Apple's own app icons (Finder, App Store,
Safari) -- those designs are Apple trademarks/trade dress. Licensed under
the same terms as the rest of this repository.

| File | Replaces (MacTahoe file) | Used by |
|---|---|---|
| parcher.svg | file-manager.svg (+ ~45 aliases, incl. org.gnome.Nautilus) | Parcher |
| parcha-store.svg | softwarecenter.svg (+ ~45 aliases, incl. org.gnome.Software) | Parcha Store |
| pafari.svg | web-browser.svg (+ ~70 aliases, incl. org.gnome.Epiphany) | Pafari, generic browsers |
| parcha-browser.svg | safari.svg | Parcha Browser |

Motif: passion fruit (purple rind, golden pulp, dark seeds, green leaf).
The seed pattern is drawn procedurally, not taken from the CC BY 3.0 logo.
