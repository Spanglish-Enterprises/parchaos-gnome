# ParchaOS app icons

Original ParchaOS artwork (hand-written SVG), made to replace icons in the
ParchaOS theme that reproduce Apple's own app icons (Finder, App Store,
Safari) -- those designs are Apple trademarks/trade dress. Licensed CC BY-SA 4.0
(see LICENSE-ARTWORK at the repository root).

The `parchaos-*.svg` icons are generated by `generate.py` (shared tile,
palette and per-app motifs); edit the script and re-run it rather than
editing the SVGs. Each motif is deliberately different from the
corresponding Apple design: ParchaOS keeps the familiar layout but has its
own look.

Motif: passion fruit (purple rind, golden pulp, dark seeds, green leaf).
The seed pattern is drawn procedurally.
